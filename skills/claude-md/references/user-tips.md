# User Tips

<!-- v1.0.0 | 2026-01-30 -->

Helpful shortcuts and features to share with users.

| Tip | Description |
|-----|-------------|
| `#` shortcut | Press `#` during session to auto-incorporate learnings |
| `.claude.local.md` | For personal preferences (add to `.gitignore`) |
| `~/.claude/CLAUDE.md` | User-wide defaults across all projects |
| `.claude/rules/` | Auto-loaded detailed rules (progressive disclosure) |
| `.claude/reference/` | Large docs NOT auto-loaded (search-triggered) |
